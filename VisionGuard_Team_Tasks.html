Deep Dive: AI / ML Pipeline & Frame Ingestion Architecture

1 1. Real-Time Frame Ingestion & Threading Strategy (Rafay)

To prevent video lag, OpenCV frame capture is decoupled from GPU inference using background daemon threads:

• Daemon Threading: prototype/camera/webcam.py continuously streams raw frames into a 2-slot circular buffer.

• Adaptive Dropping: If GPU inference takes 30ms, stale frames in buffer are automatically dropped, ensuring the model always receives the latest frame.

2 2. PyTorch GPU Multi-Model Pipeline (Moiz & Rafay)

Each video frame passes through a 3-layer neural network pipeline inside prototype/ai/pipeline.py:

• Layer 1 (Object Detection): YOLOv8s (COCO 80 classes) detects persons, cars, bikes, backpacks, laptops.

• Layer 2 (Multi-Object Tracking): ByteTrack assigns persistent Track IDs (e.g. VG-001, VG-002) across frames.

• Layer 3 (Pose & Classifier Verification): YOLOv8-Pose extracts 17 body keypoints. If aggressive keypoint angles are detected, cropped person bounding boxes are passed to custom violence_classifier_best.pt for instant verification.

Voice Command Engine & AI Narrator Execution Flow

1 Step 1: Speech Capture (Web Speech API)

The operator speaks into the Chrome browser interface. The browser's native Web Speech API converts spoken audio to text (e.g. "Open Saddar street camera and tell me what happened").

2 Step 2: Gemini Intent Parsing (`prototype/voice/interpreter.py`)

The speech transcript is sent to Google Gemini 2.0 Flash API via FastAPI endpoint. Gemini parses natural language into structured JSON action commands:

{ "action": "switch_camera", "location": "saddar", "camera_id": "CAM-042", "generate_report": true }

3 Step 3: Action Execution & WebSocket Dashboard Update

FastAPI backend (`prototype/voice/executor.py`) receives JSON commands, updates live feeds on `dashboard.html` via WebSockets, and fetches active logs for CAM-042.

4 Step 4: Spoken Bilingual Report Generation (`prototype/voice/narrator.py`)

Gemini LLM generates a concise emergency summary in both English and Urdu script. Browser Text-to-Speech (TTS) speaks the report back to the operator.

Data Science Pipeline: Code Implementation (Areeba & Moiz)

1 Step 1 Code: Complete Data Cleaning, Integrity Check & Annotation Audit Script

Required Tools: opencv-python, hashlib, os. Purges unreadable/0-byte JPEGs, eliminates duplicate images via MD5 hashing, and audits bounding box labels.

# Complete Python Code for Step 1: Data Cleaning & Bounding Box Audit import os, cv2, hashlib def clean_dataset_and_fix_labels(dataset_dir): seen_hashes = set() removed_corrupt = 0 removed_duplicates = 0 fixed_labels = 0 for root, dirs, files in os.walk(dataset_dir): for file in files: file_path = os.path.join(root, file) # 1. Image File Integrity Check (OpenCV) if file.lower().endswith(('.jpg', '.jpeg', '.png')): img = cv2.imread(file_path) if img is None or img.size == 0: os.remove(file_path) removed_corrupt += 1 continue # 2. Duplicate Image Hash Removal (Hashlib MD5) img_hash = hashlib.md5(img.tobytes()).hexdigest() if img_hash in seen_hashes: os.remove(file_path) removed_duplicates += 1 continue else: seen_hashes.add(img_hash) # 3. YOLO Label Annotation Audit (Bounding Box 0-1 Normalization Audit) elif file.endswith('.txt') and file != 'classes.txt': valid_lines = [] with open(file_path, 'r') as f: lines = f.readlines() for line in lines: parts = line.strip().split() if len(parts) == 5: cls, x, y, w, h = map(float, parts) if 0 <= x <= 1 and 0 <= y <= 1 and 0 <= w <= 1 and 0 <= h <= 1: valid_lines.append(line) with open(file_path, 'w') as f: f.writelines(valid_lines) fixed_labels += 1 print(f"Step 1 Complete: Removed {removed_corrupt} corrupt images, {removed_duplicates} duplicates, audited {fixed_labels} labels.")

2 Step 2 Code: Class Balancing & Albumentations Augmentation Script

Required Tools: albumentations. Balances minority classes and injects weather (rain, fog, shadow) variations for real-world reliability.

# Complete Python Code for Step 2: Class Balancing & Synthetic Weather Augmentation import albumentations as A import cv2, os transform_pipeline = A.Compose([ A.HorizontalFlip(p=0.5), A.RandomBrightnessContrast(brightness_limit=0.2, contrast_limit=0.2, p=0.4), A.RandomRain(brightness_coefficient=0.9, drop_density=0.1, p=0.2), A.RandomFog(fog_coef_lower=0.1, fog_coef_upper=0.3, p=0.2), A.RandomShadow(num_shadows_lower=1, num_shadows_upper=3, p=0.25), A.ShiftScaleRotate(shift_limit=0.0625, scale_limit=0.1, rotate_limit=15, p=0.3) ]) def balance_and_augment_class(input_dir, output_dir, target_multiplier=3): os.makedirs(output_dir, exist_ok=True) for img_name in os.listdir(input_dir): img_path = os.path.join(input_dir, img_name) image = cv2.imread(img_path) if image is None: continue cv2.imwrite(os.path.join(output_dir, img_name), image) for i in range(target_multiplier): augmented = transform_pipeline(image=image)['image'] aug_name = f"aug_{i}_{img_name}" cv2.imwrite(os.path.join(output_dir, aug_name), augmented) print(f"Step 2 Complete: Class augmented successfully! Saved to {output_dir}")
